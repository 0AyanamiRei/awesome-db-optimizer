# L10 · 用有限集合描述结果

原文：§7.1.1 Sets，印刷页 209–211，[PDF 第 230–232 页](../../Query%20opt.pdf#page=230)。本节建立集合、schema 兼容、特征函数、NULL 比较和集合线性的基础。订单例子与证明是教学展开。

第五章和第六章描述了谓词与约束。现在需要先确定一个查询表达式的结果是什么对象。最简单的对象是集合：一个元素要么出现，要么不出现，不记录出现次数，也不记录顺序。

## 集合和类型

设 `D` 是一个元素域。集合 `S` 是从 `D` 中取出的有限元素集合。查询结果通常由 tuple 构成，因此两个集合做并、交或差时，必须有相同的 schema：属性名和属性域都要对应。否则表达式没有类型，不能直接计算。

集合的三个基本运算是：

- 并：`X ∪ₛ Y`，出现在任一边的元素都保留；
- 交：`X ∩ₛ Y`，只保留两边都出现的元素；
- 差：`X \ₛ Y`，保留在 `X` 中但不在 `Y` 中的元素。

并和交满足交换律、结合律、幂等律；差一般不满足交换律或结合律。例如 `X \ₛ Y` 和 `Y \ₛ X` 通常不同。

## 用特征函数表示集合

与其反复说“元素是否出现”，不如为每个元素记录一个 0/1 值。集合 `S` 的特征函数写作 `χₛ`：

> `χₛ(x) = 1`，如果 `x ∈ S`；
>
> `χₛ(x) = 0`，如果 `x ∉ S`。

有限集合与这种特征函数是一一对应的：知道所有 `χₛ(x)`，就知道集合中有哪些元素；知道集合，也能计算每个特征值。

因此集合相等可以写成：

> `S = T` 当且仅当对所有 `x`，`χₛ(x) = χₜ(x)`。

子集关系也可以逐点表达：

> `S ⊆ T` 当且仅当对所有 `x`，`χₛ(x) ≤ χₜ(x)`。

集合的基数是所有特征值之和：

> `|S| = Σₓ χₛ(x)`。

因为本章只处理有限集合，这个和是有限的。只含一个元素的集合叫 singleton；它的基数是 1。

## NULL 仍然需要明确相等语义

如果元素是 tuple，集合成员判断必须知道两个 tuple 何时算相同。假设 `x` 和集合中的 `y` 都在某个属性上为 NULL。如果沿用 SQL `=`，比较结果是 UNKNOWN，无法稳定判断 `x` 是否是集合成员。原书因此要求这里使用第五章的点等号 `≐`。

例如集合中有一个 tuple `[a:NULL]`，另一个输入也是 `[a:NULL]`；按点等号，它们是同一个集合元素，不能被错误地看成两个不同的 NULL 元素。

这条约定会在 Bag 中更关键：三个 NULL 值应该形成一个重数为 3 的元素，而不是三个各自重数为 1 的“不同元素”。

## 集合线性的预告

原书在 7.1.1 末尾引入 set-linearity，也叫 homomorphism。一个从集合到集合的一元函数 `f` 是集合线性的，如果：

> `f(∅) = ∅`
>
> `f(X ∪ₛ Y) = f(X) ∪ₛ f(Y)`

二元或多元算子可以分别检查每个参数是否满足同样的空输入和分配条件。它的用途是把“对任意大集合成立”的证明缩减为“对 singleton 成立”的证明，但前提是两边确实都是相应的线性函数。

集合运算本身并不全部线性：交是集合线性的，差只在左参数上线性，并集由于空集和重复分解的关系不能简单地按两侧都线性处理。这个结论会在后续算子重排中再次出现。
