# L09 · FD、NULL、重复行与算子传播

原文：§6.2–§6.4，印刷页 208，[PDF 第 229 页](../../Query%20opt.pdf#page=229)。这三节在原书中大多没有写完，先看清哪些是原文：

| 小节 | 原书写了什么 | 本节怎么处理 |
| --- | --- | --- |
| §6.2 含 NULL 的 FD | 一个定义，随后是 `XXX explain why, discuss lax dependencies` | 解释定义，补上“为什么” |
| §6.3 算子上的 FD 推导 | 只有 `XXX dependency graphs` | 给出标明为教学补充的检查表 |
| §6.4 Bibliography | 只有标题 | 不处理 |

> **本节回答三个问题**
>
> 1. 列里有 NULL 时，FD 定义中的“相同”怎么比较？
> 2. FD 成立，是否说明没有重复行？
> 3. 经过选择、投影、连接之后，哪些 FD 还能用？

## 1. NULL 让普通 `=` 失灵

先回忆第五章的三种比较（L02、L05）：

| 比较 | `NULL` 与 `NULL` | `NULL` 与 `1` | `1` 与 `1` |
| --- | --- | --- | --- |
| SQL 相等 `=` | UNKNOWN | UNKNOWN | TRUE |
| 点等号 $\doteq$ | TRUE | FALSE | TRUE |
| `=⁻`（UNKNOWN 按 FALSE 解释） | FALSE | FALSE | TRUE |

看这张表（教学补充）：

| `A` | `B` |
| --- | --- |
| NULL | 7 |
| NULL | 8 |

直觉上它违反了 `A → B`：两行的 `A` “一样”，`B` 却不同。但如果照搬 L07 的定义，前提是 `NULL = NULL`，结果为 UNKNOWN。“UNKNOWN ⇒ …” 该算成立还是违反？定义没有给出答案。

如果改用 `=⁻`，前提变成 FALSE，蕴含式自动为真，这张表反而被判定为**满足** `A → B`。这不是我们想要的：NULL 列上的 FD 会形同虚设。

## 2. 原书的定义：改用点等号（原文）

原书把定义中的 `=` 换成点等号：

$$
\forall t_1, t_2\;\big([\,t_1 \in R \land t_2 \in R \land t_1.A_1 \doteq t_2.A_1\,] \Rightarrow [\,t_1.A_2 \doteq t_2.A_2\,]\big)
$$

读法和 L07 完全一样，只是“相同”改为：**两个 NULL 算相同，NULL 和非 NULL 值算不同。** 点等号永远只给出 TRUE 或 FALSE，定义不再悬空。

| 数据 | `A → B` | 理由 |
| --- | --- | --- |
| (NULL, 7), (NULL, 7), (1, 9) | 满足 | 两行 NULL 在 `A` 上相同，在 `B` 上也相同 |
| (NULL, 7), (NULL, 8) | 违反 | `A` 上相同，`B` 上不同 |
| (NULL, 7), (1, 8) | 满足 | NULL 与 1 不同，不构成比较对 |

这和第七章集合、bag、分组判断“是否相同”的方式一致：分组时所有 NULL 进同一组。

原书的 `XXX` 还提到 lax dependencies，但没有定义，本教材不展开。

### 别把它和等价类混为一谈

L06 为 WHERE 条件收集 `=⁻` 等价类；这里用 $\doteq$ 定义约束。两者都避免了 UNKNOWN，但用途不同：

| 对象 | NULL 与 NULL | 用在哪里 |
| --- | --- | --- |
| SQL `A = B` | UNKNOWN | 写查询条件 |
| `A =⁻ B` | FALSE | WHERE 中的二值化谓词，建立等价类（L06） |
| $A \doteq B$ | TRUE | 定义含 NULL 的 FD |

## 3. FD 成立 ≠ 没有重复行

FD 比较的是**值**，不关心一行出现了几次。看这个 bag：

| `id` | `name` |
| --- | --- |
| 1 | Ada |
| 1 | Ada |
| 2 | Lin |

`id → name` 成立：`id` 相同的行，`name` 都相同。按 L08 的定义，`id` 甚至决定了全部属性，是“超键”。可是 `(1, Ada)` 出现了两次，`id` 并不能唯一标识一行。

所以要分清两种信息：

| 信息 | 回答的问题 | 例子 |
| --- | --- | --- |
| 值层 FD | 左值相同，右值是否相同 | `id → name` |
| 无重复 / 行身份 | 同一组值最多出现几次 | `id` 上的 UNIQUE 约束，或第七章的 TID |

L08 的超键和键只在关系是集合（没有重复行）时，才等于“能唯一标识一行”。进入第七章的 bag 之后，只凭一条 FD 不能证明结果无重复，也不能单凭它删除一个可能放大重复的连接。

## 4. 经过算子后 FD 怎么变（原书缺失，教学补充）

§6.3 本应给出“每个算子输出哪些 FD”，原书只留下 `XXX dependency graphs`。下表是不含 NULL 情形下的常见结论，仅作为读后续章节的检查入口，不是原书定理：

| 算子 | 输入的 FD | 新增的 FD |
| --- | --- | --- |
| 选择 $\sigma_p(R)$ | 全部保留（只删行，不会制造反例） | $p$ 合取地含 `A = B` 时得 `A → B`、`B → A`；含 `A = 常量` 时得 `∅ → A` |
| 重命名 | 按新名字保留 | 无 |
| 投影 $\Pi_X(R)$ | 先在 $F^+$ 中推导，再保留只涉及 $X$ 的 FD | 无 |
| 连接 $R \bowtie_p S$ | 两侧的 FD 都保留 | 与选择相同，来自连接谓词 |
| 分组（按 $G$） | 需要逐个检查 | $G$ 决定全部输出列，每组一行 |

两点提醒：

- **投影要先推导再丢列。** 若有 `A → B`、`B → C`，投影掉 `B` 后，`A → C` 仍然成立。只看原来列出的 FD 会把它漏掉。
- **NULL 和外连接需要另行论证。** 外连接会补 NULL，谓词中的 `=` 可能是 UNKNOWN，上表的“新增”一栏不能直接照搬。第七章给出算子定义后再逐个检查。

### 依赖图的局限

把 `A → B` 画成一条从 `A` 到 `B` 的边，能帮助看清传递链。但多列左边的 FD 画不成单条边。以 L08 自测题 $F = \{A \to B,\; B \to C,\; AC \to D\}$ 为例，如果把 `AC → D` 拆成 `A → D` 和 `C → D` 两条边，就会错误地推出 `C → D`。正确做法是 L08 的属性闭包：只有 `A`、`C` 都进入闭包后，才能使用 `AC → D`。

## 第六章小结

```text
L07  FD 的定义          左边相同 ⇒ 右边相同；有方向；来自 schema 和算子
L08  推理与键           Armstrong 公理 → 属性闭包 → 超键 / 键
L09  边界               NULL 用点等号比较；FD 不保证无重复；算子传播原书未写
```

以后遇到一条依赖 FD 的优化规则，先问三个问题：

1. 这条 FD 是 schema 或算子保证的，还是当前数据碰巧满足？
2. 列可能是 NULL 吗？比较用的是 `=`、$\doteq$ 还是 `=⁻`？
3. 规则只需要值层 FD，还是还需要“无重复”？

**自测**：表 $T(A, B)$ 的数据是 (NULL, 1)、(NULL, 1)、(2, 3)。按原书定义 `A → B` 成立吗？`A` 能唯一标识一行吗？

<details>
<summary>答案</summary>

`A → B` 成立：两行 NULL 按点等号相同，`B` 都是 1。但 `A` 不能唯一标识一行：(NULL, 1) 出现了两次。这正是第 2、3 部分的两个要点。

</details>
