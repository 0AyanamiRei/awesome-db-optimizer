当 I/O 单位改变抽样分布：Block-Level Sampling 的统计修复

均匀抽 2% 的行仍可能触碰大量磁盘块；直接抽 2% 的块虽然便宜， 却会把物理聚簇带进统计样本。本文沿 SIGMOD 2004 的 Effective Use of Block-Level Sampling in Statistics Estimation， 分别精讲 Histogram 的 2PHASE 与 NDV 的 COLLAPSE，并严格标出它们能保证什么、不能保证什么。

0. 为什么值得单独讲：这是“物理抽样单位”的问题

对应论文摘要与 §1。 PDF p.1 / 论文 p.287

在统计教材里，“抽取 \(q\) 比例的数据”很容易被写成一个抽象动作；在存储系统里， 一次 I/O 通常读回的是一个 page、block、row group 或 tablet，而不是一条孤立的 row。 如果一个块约有 50 行，做 2% 的均匀行抽样，平均每块恰好命中约 1 行。 在独立 Bernoulli 近似下，一块至少命中一行的概率是 \(1-(1-0.02)^{50}\approx63.6\%\)：不是字面上的“几乎每块”，但已经意味着读取约 64% 的块， 且 \(1-(1-q)^b\) 会随 \(qb\) 增大迅速逼近 1。Block sampling 的诱惑由此而来： 随机选少量块，再取走块内全部行。

本文回答

  • 为什么同样的 sample fraction，不等于同样的统计信息？
  • 如何按数据的 block clustering 自适应决定 Histogram 样本量？
  • 为什么现成 NDV estimator 在 block sample 上会灾难性低估？
  • COLLAPSE 的证明究竟等价到哪一层？

本文不声称

  • 2PHASE 给出高概率误差保证。
  • COLLAPSE 把 block sample 变成原表的均匀 row sample。
  • 论文的单列 NDV 结果可直接替代任意多列 GROUP BY estimator。
  • 2004 年磁盘实验可以不经复核地外推到所有现代存储层。

先记住两条互不替代的主线

2PHASE 解决的是 Histogram 构建需要抽多少行； COLLAPSE 解决的是怎样把 block sample 交给某类 NDV estimator。 两者都以 block layout 为问题起点，但目标、证明和输出完全不同。

1. 从 row、block 到 sample：先把随机性写清楚

对应论文 §1、§3.1。 PDF p.1 / 论文 p.287 PDF p.3 / 论文 p.289

\(N\)表中的 block 数
\(b\)每个 block 的行数
\(n=Nb\)表的总行数
\(q=R/N=r/n\)block / row 抽样率
相同 q 下，两种抽样设计的随机单位与代价
设计 随机单位 拿到的行 主要优势 主要风险
Uniform row sampling 每一行 散布在许多块中的约 \(r=qn\) 行 经典 estimator 的抽样假设更直接 随机 I/O；小样本也可能触碰大量块
Uniform block sampling 每一个块 约 \(R=qN\) 个整块，共 \(r=Rb\) 行 I/O 连续，读到一块就利用其全部行 块内行相关；物理 layout 进入 estimator

“随机抽 block”不等于“随机抽 row”

每个 block 被均匀选中，只能推出每一行具有相同的边际入样概率 \(q\)； 同一块内的行会一起入样，彼此高度相关。Histogram 与 NDV estimator 依赖的不只是 单行入样概率，还依赖联合分布、频数和方差。

2. Histogram：先定义“够准”，再问抽多少

对应论文 §3.1–§3.2、Algorithm DOUBLE。 PDF p.3 / 论文 p.289

设最终 Histogram 有 \(k\) 个 bucket，真实 bucket 计数为 \(n_i\)， 从样本放大得到的估计为 \(\hat n_i\)。论文主要使用 variance error，也给出 max error 作为对照：

Equation (1)：variance error，按平均 bucket 大小归一化的 RMS error \[ \Delta_{\mathrm{var}} = \frac{k}{n} \sqrt{\frac{1}{k}\sum_{i=1}^{k}(\hat n_i-n_i)^2} \]
Equation (2)：max error，只盯最坏 bucket \[ \Delta_{\max} = \max_i \left\{ \frac{|\hat n_i-n_i|}{n/k} \right\} \]

\(\Delta_{\mathrm{var}}=0.25\) 可以直观理解为：bucket 计数的 RMS 偏差约等于 “平均 bucket 大小”的 25%。论文选择它，是因为 max error 容易被单个异常 bucket 支配，作为自适应停止条件过于保守。

没有真值时，怎样知道当前样本够不够？

取两份大小同为 \(r\) 的独立 block sample \(S_1,S_2\)，先在 \(S_1\) 上构建 Histogram \(H\)。保持 \(H\) 的同一组 bucket separators，分别统计 \(S_1\) 与 \(S_2\) 的 bucket counts \(\tilde n_i,\tilde m_i\)，论文对这一个方向定义：

Equation (3)：cross-validation error \[ \Delta_{\mathrm{CV}} = \frac{k}{r} \sqrt{\frac{1}{k}\sum_{i=1}^{k}(\tilde n_i-\tilde m_i)^2} \]

Equation (3) 本身不同时包含“反向验证”。后续 2PHASE 的 sortAndValidate 会在左右子样本之间交换训练/验证角色，取得第二个独立的 squared-error observation，再把同一尺度的多次观测求均值。

DOUBLE 的工作方式

  1. 从均匀行抽样理论给出的 \(r_{\mathrm{unf}}\) 开始。
  2. 采两份样本，计算 \(\Delta_{\mathrm{CV}}\)。
  3. 未达目标就把样本量翻倍，再试一次。
  4. 达标后使用样本构建 Histogram。

为什么它会浪费

  • 每一轮采样都有固定启动开销。
  • 指数增长天然会越过“刚好够用”的 \(r_{\mathrm{blk}}\)。
  • 把最后一次验证也计入，论文分析最坏可接近 \(4r_{\mathrm{blk}}\)。
  • 它观察到误差，却没有显式利用 \(1/r\) 的规律。

理论分析先固定 bucket separators

后续定理把 bucket 边界视为预先给定，因此直接覆盖的是 equi-width 一类情形。 Equi-depth、MaxDiff 的边界会随样本改变，不满足这项假设；论文对它们给的是实验支持， 不是同一个定理的形式化保证。

3. Theorem 1：布局如何变成所需样本量

对应论文 §3.3、Theorem 1。 PDF p.4 / 论文 p.290

对每个 bucket \(i\) 和 block \(j\)，定义 \(a_{ij}\) 为： “block \(j\) 中落入 bucket \(i\) 的行所占比例”。令 \(\sigma_i^2\) 是 \(a_{i1},\ldots,a_{iN}\) 在所有块之间的方差。

Theorem 1：两份独立 block sample 的期望平方 CV error \[ \mathbb{E}\!\left[\Delta_{\mathrm{CV}}^2\right] = \frac{2kb}{r}\sum_{i=1}^{k}\sigma_i^2 \]

论文对 Equation (4) 的拆解还给出一个实用关系：两份独立样本各贡献一个相同的方差项， 而真正 Histogram 相对总体的 squared variance error 只对应其中一项。因此在相同假设下， \(\mathbb E[\Delta_{\mathrm{CV}}^2] =2\mathbb E[\Delta_{\mathrm{var}}^2]\)，CV error 的典型量级约是真实 variance error 的 \(\sqrt 2\) 倍。也就是说，用 CV target 停止通常偏保守，而不是把验证误差当成真实误差。

样本 \(r\) 翻倍 → 期望平方误差减半 block 越大 \(b\) 越大 → 同行数的信息越相关 bucket 越多 \(k\) 越大 → 更多边界要估 布局越聚簇 → \(\sum\sigma_i^2\) 越大

Hist Badness：把“物理布局不友好”压缩成一个量

论文定义 \[ \mathrm{HistBadness}=\sum_{i=1}^{k}\sigma_i^2 \]

从定理反推样本量

若目标是 \(\Delta_{\mathrm{req}}\)，形式上可把误差曲线写成 \(\Delta^2=c/r\)，其中 \(c=2kb\cdot\mathrm{HistBadness}\)。问题是系统事前并不知道 HistBadness；2PHASE 的第一阶段正是用一小批 block sample 估计这个 \(c\)。

Expectation 不是 guarantee

定理给出的是 \(\mathbb{E}[\Delta_{\mathrm{CV}}^2]\)，不是 “每次运行都满足 \(\Delta\le\Delta_{\mathrm{req}}\)”的高概率界。 论文还用“有放回抽 block”近似分析无放回抽样，并假设每块恰有 \(b\) 行、bucket 边界固定。 这些假设必须与公式一起读，不能只摘出 \(1/r\) 曲线。

4. 2PHASE：用一次初始样本预测，而不是反复翻倍

对应论文 §3.3–§3.4、Algorithm 2PHASE。 PDF p.5 / 论文 p.291

Phase I：一次取得 \(2r_1\) 行

论文建议 \(r_1\) 可从均匀 row sampling 的理论样本量 \(r_{\mathrm{unf}}\) 起步； 实验中取其 2–3 倍更稳健。这里的 \(2r_1\) 会被复用，而不是只做一次性验证。

sortAndValidate：从一份样本制造多尺度观测

像 merge sort 一样递归把样本切半：每层左右子样本互相 cross-validate， 记录该层的 \((r,\Delta_{\mathrm{CV}}^2)\)，再把已排序结果 merge。 论文经验上让递归深度 \(l_{\max}\) 约为 3。

拟合 \(c\)，预测目标 \(r_{\mathrm{blk}}\)

若最初样本已经足够，就返回 \(2r_1\)；否则用多个尺度的误差点最小二乘拟合 \(\Delta^2=c/r\)，再算 \(r_{\mathrm{blk}}=c/\Delta_{\mathrm{req}}^2\)。

Phase II：补齐一次，合并构建

只再采 \(r_{\mathrm{blk}}-2r_1\) 行对应的块，与第一阶段的排序样本合并， 最终构建 Histogram。第一阶段数据全部进入最终产物。

2PHASE 选择“不做最终验证”

Phase II 后算法直接构建 Histogram，因此目标是期望意义上的误差。 论文讨论了两种更强做法：推导高概率界，或追加重复/最终验证；前者可能很保守， 后者会重新引入额外采样和 oversampling。2PHASE 的效率正来自这项明确取舍。

5. NDV：为什么 TAKEALL 会把“块内重复”误读成“全表重复”

对应论文 §4.1–§4.2。 PDF p.6 / 论文 p.292

NDV（number of distinct values）常用于 Histogram bucket density 和等值选择率。 令真实 NDV 为 \(D\)，一次估计为 \(\hat D\)。论文刻意区分 bias 与 ratio error：

Bias 看跨重复实验的期望；ratio error 看一次估计偏离真值的倍数 \[ \mathrm{Bias}=\left|\mathbb E[\hat D]-D\right|, \qquad \mathrm{Error}=\max\left\{\frac{\hat D}{D},\frac{D}{\hat D}\right\} \]

完美 ratio error 是 1；一个 estimator 可以无偏，却仍因方差很大而有很高的期望 ratio error。 对一份样本，再令 \(d\) 为样本中不同值数，\(f_i\) 为“在样本里恰好出现 \(i\) 次”的值数。 很多经典 estimator 可概括为：

典型 unseen-species 修正 \[ \hat D = d + K f_1 \]

\(d\) 是已经看见的值；\(f_1\)（singleton 数量）提供“还有多少 unseen values” 的信号。TAKEALL 的做法很直接：把抽中块里的每一行全部拿来，假装这是一份均匀 row sample， 再调用现成 estimator。危险恰恰来自这个“假装”。

错误不在“重复值太多”，而在重复的来源被混淆

均匀 row sample 中，一个值重复出现通常说明它在全表频繁； block sample 中，它也可能只是因为该值被物理聚簇在刚好抽中的块里。 TAKEALL 丢掉了 block identity，无法区分这两种原因。

论文同时指出：针对 block sampling 设计一个达到指定 NDV 精度的自适应样本量算法， 在该工作中仍是开放问题。COLLAPSE 修复的是“已有 block sample 如何估 NDV”， 不是 NDV 版的 2PHASE。

6. COLLAPSE：先构造虚拟表，再复用已有 estimator

对应论文 §4.2、Lemma 1、Theorem 2。 PDF p.7 / 论文 p.293

算法动作只有一句，但证明对象要换

以概率 \(q\) 抽取 block。对每个已抽中的 block，把同一 value 的多次出现 collapse 成一次；把得到的 \(S_{\mathrm{coll}}\) 交给一个原本面向 均匀抽样的 NDV estimator，并仍使用抽样率 \(q\)。

为理解它，定义虚拟表 \(T_{\mathrm{coll}}\)：对原表的每一个 block 都做相同的块内去重。若值 \(j\) 在原表中出现 \(n_j\) 次、分布在 \(N_j\) 个块， 那么它在 \(T_{\mathrm{coll}}\) 中恰好出现 \(N_j\) 次。

Lemma 1：为什么 \(f_i\) 的期望相同

对值 \(j\)，它在 \(T_{\mathrm{coll}}\) 中有 \(N_j\) 个 occurrence， 一一对应原表中包含该值的 \(N_j\) 个 block。在 Bernoulli block sampling 模型下， 它恰好在样本出现 \(i\) 次的概率为：

对单个值 j 的入样频数 \[ \Pr[F_j=i] = {N_j\choose i}q^i(1-q)^{N_j-i} \]

这正是以概率 \(q\) 均匀抽取 \(T_{\mathrm{coll}}\) 中该值的 \(N_j\) 个 occurrence 时的二项分布。因此，对所有值求和后， \(\mathbb E[f_i(S_{\mathrm{coll}})] =\mathbb E[f_i(S_{\mathrm{unf}}(T_{\mathrm{coll}}))]\)。

假设边界：Lemma 1 使用 Bernoulli sampling——每个 block / item 独立地以概率 \(q\) 入样；论文把它视为大表上固定大小均匀抽样的近似。\(T_{\mathrm{coll}}\) 的虚拟 block 在去重后可以大小不一，这不影响上述按 value 计数的证明；但多个 value 共享同一 block 仍会造成联合相关。

Theorem 2：线性 frequency estimator 的 bias 被保留

适用 estimator 形式；系数 \(a_i\) 只能依赖 q，不能依赖样本的 \(f_i\) \[ \hat D=\sum_i a_i f_i \]

因为期望可线性穿过求和，COLLAPSE 在原 block sample 上运行该 estimator 的 bias， 与 estimator 在 \(T_{\mathrm{coll}}\) 的均匀样本上运行时相同。论文以 GEE 为例：

GEE 示例 \[ \hat D_{\mathrm{GEE}} = \sum_{i\ge 2} f_i + \frac{f_1}{\sqrt q} \]

证明了

对指定线性 estimator，COLLAPSE 与 \(T_{\mathrm{coll}}\) 均匀样本具有相同 bias。

没有证明

方差、ratio error 或某次运行的误差相同；也没有说样本联合分布完全相同。

不能直接覆盖

AE、HYBSKEW 等系数依赖观测 \(f_i\) 的 estimator；论文对其表现给实验结果。

COLLAPSE 改变了问题中的 multiplicity

原值 \(j\) 的频数是 \(n_j\)，虚拟表中的频数是 \(N_j\)。 两张表的 NDV 相同，但频数分布不同。之所以还能估 NDV，是因为目标只关心 “有哪些值”，而不是保留原表每个值出现多少次。

7. 下界与两种 Badness：COLLAPSE 也不能消除所有 block correlation

对应论文 Theorem 3、§4.3。 PDF p.7 / 论文 p.293 PDF p.8 / 论文 p.294

论文构造两个难以区分的数据库，说明只抽取 \(N\) 个 block 中的 \(R\) 个、 每块 \(b\) 行时，任何 NDV estimator 都无法普遍给出优于下列量级的 ratio-error 保证：

Theorem 3 的下界量级；写成 block 数与 row 数两种形式 \[ \sqrt{\frac{Nb}{R}} = \sqrt{\frac{nb}{r}} \]

论文原文表述为：不存在能对所有输入以高概率保证 ratio error “小于 \(O(\sqrt{Nb/R})\)”的 estimator。这里保留其原始渐近记号； 按下界语义理解，就是不能给出渐近优于该量级的普遍保证。

对相同行数 \(r\) 的均匀 row sample，经典下界量级少一个 \(\sqrt b\) 因子。 直觉是：一次抽中整块带来 \(b\) 行，却未必带来 \(b\) 份独立证据。 COLLAPSE 能修复某些 estimator 的 bias，但不能违反信息论下界。

DV Badness 与 Hist Badness 不是同一个旋钮

令 \(d_j\) 是 block \(j\) 内的不同值数。论文用其变异系数衡量 NDV 任务对布局的敏感性：

论文定义 \[ \mathrm{DVBadness} = \frac{\sigma(d_j)}{\mu(d_j)} \]

一个容易反直觉的例子

完全按值聚簇会把某个 Histogram bucket 集中到少量块，因而 HistBadness 很高； 但如果每块都稳定地装着相同数量的 distinct values，\(d_j\) 几乎不变， DVBadness 反而可能很低。论文实验中，完全聚簇时 COLLAPSE 甚至可能优于均匀 row sample； 这不是“block sample 普遍更好”，而是该数据的 NDV 信息恰好按块分布得很稳定。

实验设置与能支持的结论
维度 论文设置 阅读时应注意
实现环境 SQL Server 原型；Intel 2.3GHz、1GB 内存 结论来自磁盘时代的采样成本模型；算法洞见可迁移，绝对时间不能直接外推。
合成表规模 \(10^5\)–\(10^7\) 行；block size 50–200；Zipf \(Z=0\)–2 覆盖了规模、skew、block size，但不是任意存储格式或并发场景。
聚簇控制 比例 \(C\) 的 occurrence 连续编号，其余随机；\(C=0\) 随机，\(C=1\) 完全聚簇 这是可控的一维 clustering 生成器，不代表所有多列/分区/LSM layout。
Histogram Equi-depth 与 MaxDiff；常用 \(k=100,b=132,\Delta_{\rm req}=0.25\) 形式化推导固定 separators；动态边界算法主要由实验验证。
NDV AE、HYBSKEW × COLLAPSE / TAKEALL；与 UNIFORM 比较 Theorem 2 严格覆盖线性 frequency estimator；AE/HYBSKEW 结论是经验性的。
真实数据 Home：667,877 行，按 neighborhood 聚簇；zipcode，约 25 行/block 只有一张规模不到百万的真实表，不能单独证明跨 workload 普适性。
重复次数 Histogram 多为 5 次均值；NDV ratio error 多为 10 次均值 均值展示总体趋势，不等于 tail guarantee 或显著性分析。

论文实验真正稳定支持的趋势

Histogram / 2PHASE

  • 所需样本量对总表规模相对不敏感，更受 layout、\(b\)、\(k\) 和目标误差影响。
  • clustering 增强时，block sample 需要更多行；2PHASE 能从 Phase I 估出趋势。
  • DOUBLE 常因翻倍和多轮固定开销 oversample；部分设置中约有 4× 差距。
  • MaxDiff 在 skew 增强时可用更少样本；Equi-depth 对 skew 较不敏感。

NDV / COLLAPSE

  • TAKEALL 在低 sample fraction 下 ratio error 可非常大，论文图中有接近 200 的案例。
  • clustering 增强时 TAKEALL 恶化；COLLAPSE 通常保持接近 UNIFORM。
  • 完全聚簇时 COLLAPSE 可能因低 DVBadness 优于 UNIFORM。
  • 高 skew 下偶见 HYB_TAKEALL “胜出”，论文解释为高估与低估的误差抵消。

不要把图上的极值写成普遍常数

“TAKEALL 误差约 200”或“DOUBLE 多抽 4×”都是特定参数、数据和 estimator 下的观测， 不是算法对所有输入的固定误差。更可靠的教学结论是： 物理聚簇会系统性破坏 naive block-sample estimator，而 2PHASE / COLLAPSE 对应地缓解了样本量与频数语义问题。

从 2004 迁移到今天，要重新测什么？

  • 物理抽样单位从 page/block 变成 row group、segment、stripe 或 tablet 后，块内相关性怎样变化？
  • 压缩、列存和异步预取改变了“随机 row I/O 很贵”的程度，但是否改变 estimator 假设？
  • 分区裁剪、compaction、sort key 和冷热分层会不会让样本只代表一部分 layout？
  • 统计采集是单机、分布式聚合还是 per-part sketch merge？网络成本是否成为新的 block cost？
  • 除了平均误差，还需要报告 p95/p99、最坏分区和 optimizer plan regret 吗？

Every Row Counts 主教程 讨论的是任意多列 GROUP BY 的结果 NDV：它从均匀 row sample 提取组合 frequency vector，再用全表单列 sketch 收紧估计。本文则讨论： 当物理上只能便宜地抽整块时，如何构建单列 Histogram 与估计 单列 NDV。两篇论文都出现 sample 与 distinct，但问题轴并不相同。

为什么 COLLAPSE 不能直接喂给 Every Row Counts

  1. 样本总体不同：COLLAPSE 对应 \(T_{\mathrm{coll}}\)，CIDR 要估的是原表 \(T\) 中多列组合的 group count。
  2. multiplicity 被改写：一个组合在同一块出现 100 次，COLLAPSE 后只剩一次； CIDR 的 sample frequency vector 会把它当成真实 sampled frequency。
  3. 联合入样相关：同一块内不同组合一起出现或一起消失； COLLAPSE 的 Lemma 只给每个 \(f_i\) 的期望桥梁，没有为 CIDR 的 bounds 重做证明。
  4. sketch 约束对象不同：CIDR 的单列 sketches 描述原表全量列分布， 而 COLLAPSE sample 描述按 block-presence 改写后的频数。

可研究的组合方式，而不是可直接拼接的 pipeline

可以让收集器保留 block identity、每个组合的 sampled-block multiplicity 和原始行频数， 再按真实 inclusion probability 重新推导 estimator；也可以在抽中 block 后继续做块内 row reservoir，生成满足所需设计的二阶段样本。但这些都是新算法设计， 不能引用 COLLAPSE Theorem 2 自动获得正确性。

问题 简答 回看
为什么 block sample 更便宜，却不自动等价于 row sample？ 随机单位是块；块内 rows 联动入样，layout 造成 correlation。 §1
Histogram 所需样本量由什么决定？ \(r\)、\(b\)、\(k\) 与跨块比例方差 \(\sum_i\sigma_i^2\)。 §3
2PHASE 比 DOUBLE 多知道了什么？ 它从多尺度 CV 点拟合 \(\Delta^2=c/r\)，预测“还差多少”，而非只问“够不够”。 §4
TAKEALL 为什么会低估 NDV？ 块内重复压低 \(f_1\)，被误当成全表高频证据。 §5
COLLAPSE 的定理到底证明了什么？ 对系数只依赖 \(q\) 的线性 frequency estimator，bias 等于其在 \(T_{\rm coll}\) 均匀样本上的 bias。 §6
COLLAPSE 能当作 CIDR 的 row sample 吗？ 不能；总体、multiplicity 与联合入样结构都不同，必须重推 estimator。 §9

实现前的最小契约

  • 明确 sample 的总体、随机单位与 inclusion probability。
  • 保留 block identity，直到 estimator 明确不再需要它。
  • 分别验证 bias、variance、ratio error 与高概率 guarantee。
  • 把固定 separators、固定 block size 等假设写进接口或测试。

实验前的最小矩阵

  • 随机、部分聚簇、完全聚簇三种 layout。
  • 不同 block size、skew、NDV、Histogram bucket 数。
  • TAKEALL / COLLAPSE / row sample 对照。
  • 平均误差之外，同时记录 tail error、I/O 与计划质量。

最后的心智模型

Block sampling 不是一份“质量稍差的 row sample”，而是一种不同的 sampling design。 2PHASE 把 layout 的影响转成可估计的 Histogram 样本需求； COLLAPSE 把块内重复转成 block-presence frequency，再在严格限定的 estimator 类里迁移 bias。 两个技巧的共同价值，是不再把物理 I/O 细节藏在一个含糊的 sample fraction 后面。
