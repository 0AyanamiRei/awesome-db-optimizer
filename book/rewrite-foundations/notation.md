# 符号表：以 Moerkotte 为主

本表服务于阅读 *Building Query Compilers* Part II。正文按出现顺序逐步引入；查阅表不要求提前背诵。原文节号与版本见[资料记录](sources.md)。

## 逻辑、约束与数据对象

| 记号 | 含义与使用范围 | 原文 |
| --- | --- | --- |
| ¬、∧、∨；∀、∃ | 逻辑连接词与量词；分别指明二值或三值上下文 | §5.1–3 |
| NULL、⊥、`-` | `NULL` 是输入值标记；`⊥` 在第 5 章表示比较/逻辑结果 UNKNOWN，其他章节若表示未定义需按上下文判断；`-` 只在原文具体记号中使用，不能把它们当成同一个对象 | §5.2–3、§7.1.4、§7.2 |
| `=ᵛ` | 不含 NULL 的普通值比较；原文 v 为上标 | §5.2.2 |
| = | SQL 风格相等，任一侧 NULL 时可得到 UNKNOWN | §5.2.2 |
| ≐（原文点等号） | 两个 NULL 也相等的比较；重复判定、分组等使用它 | §5.2.2 |
| ⌊p⌋⊥、⌈p⌉⊥ | 把 UNKNOWN 分别解释为 FALSE、TRUE | §5.3 |
| =⁻、=⁺ | 普通相等后分别接 false/true interpretation；都不等于点等号 | §5.3 |
| X→Y | 函数依赖；X、Y 为属性集合 | §6.1–2 |
| F⁺ | FD 集合 F 的闭包；这里的 F 不是自由属性函数 | §6.1 |
| {…}ₛ、{…}ᵦ、⟨…⟩ | set、bag、sequence 的构造 | §7.1 |
| χ_S(x)、χ_B(x) | set 的 0/1 特征函数；bag 的非负整数重数 | §7.1.1–2 |
| χ_s(i) | sequence 第 i 个位置的值；不是重数函数 | §7.1.4 |
| ∪ₛ、∩ₛ、∖ₛ | 集合运算 | §7.1.1 |
| ∪ᵦ、∩ᵦ、∖ᵦ | Bag 的加法并、min 交、截断差；进入算子定义后原书常省略下标 | §7.1.2–3 |
| ∪max | 用最大重数定义的另一种 bag union；与本书主要使用的加法并不同 | §7.1.2 |
| a∸b | 截断减法 max(0,a−b)，对应原文带点减号 | §7.1.2 |
| Πᴰ(B) | 显式去重，重数为 min(1,χ_B(x)) | §7.1.3 |
| ε、α(s)、τ(s)、⊕ | 空序列、首元素、尾序列、序列连接 | §7.1.4 |

## 类型、表达式与算子

| 记号 | 含义与注意点 | 原文 |
| --- | --- | --- |
| e :: τ | 表达式 e 的类型是 τ；τ 在此不表示序列的 tail 函数 | §7.3.1 |
| [a:τ₁,b:τ₂] | Tuple 类型；[a:v,b:w] 则是 tuple 值 | §7.3.1 |
| {τ}ₛ、{τ}ᵦ、⟨τ⟩ | 三类 bulk type，可包含嵌套值 | §7.3.1 |
| τ₁≤τ₂ | 原书的可替换性关系，不是简单的类继承记号 | §7.3.1 |
| A(e)、F(e) | 表达式提供的属性、自由属性 | §7.3.1 |
| e(t) | 用 t 提供的绑定求值 e；名称须无歧义 | §7.3.1 |
| e[v←e′] | 变量替换；多变量须维护作用域 | §7.3.1 |
| t 限制到 X | Tuple 只保留 X 的属性；正文公式写成 t\|_X | §7.16.1 等 |
| ◦ | Tuple 拼接、函数复合或聚合向量连接，必须由操作数类型区分 | §7.2–3 |
| Π_X(e) | **保留重复的投影** | §7.3.3 |
| Πᴰ_X(e) | 去重投影，等于 Πᴰ(Π_X(e)) | §7.3.3 |
| Π 的上划线属性版本 | 删除指定属性；教材优先展开为保留 A(e)∖X，避免 PDF 上划线丢失 | §7.3.3 |
| σ_p(e) | Selection，保留谓词通过的输入项 | §7.3.4 |
| χ_f(e)、χ_{a:f}(e) | 一般 map、扩展 map；与 χ_B(x) 的重数函数区分 | §7.3.5 |
| rename_{旧→新}(e) | 教材为避免箭头歧义使用的显式别名；每次与原文 ρ 核对方向 | §7.3.5 |
| Γ^θ_{G;g:f}(e) | 按 G/θ 构造组，再以 f 求新属性 g；有聚合向量及 SQL 简写 | §7.3.6 |
| ν、μ、Υ、flatten | Nest、unnest、unnest-map、bag-of-bags 展平 | §7.3.6–8 |
| ×、⋈、⋉、▷、⟕、⟗ | Product、inner、semi、anti、left/full outer join | §7.3.9 |
| DJ(e₁,e₂) | 教材对原书 d-join 图形符号的文字别名 | §7.3.9、§7.9 |
| GJ_{q;g:f}(e₁,e₂) | 教材对 groupjoin 图形符号的文字别名；不与 Γ 混同 | §7.3.10 |
| Max_{m;g;a;f} | 同时给出最大值及对应组的函数结果；不是普通标量 max 的同义写法 | §7.3.11 |

符号转写只解决字体和排版问题，不改变定义。尤其不能把 PDF 提取出的 `B`、`C`、`E`、`Z` 当作真实算子名：这些常是原文自定义 join 字形的提取结果。

## 性质、表示和后续理论

| 记号 | 含义 | 原文 |
| --- | --- | --- |

## 仅在可选论文对照中使用的记号

Neumann 的 m_R(t) 对应本书 χ_R(t)；Neumann 的 Π⁺ 对应本书保留重复的 Π，Neumann 的 Π 对应本书 Πᴰ。`bind` 是论文对照中的显式工具，主教材使用本书 e(t) 与替换约定。不得让这些对照记号反过来覆盖本书定义。
