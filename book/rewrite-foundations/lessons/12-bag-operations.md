# L12 · Bag 运算怎样作用于重数

原文：§7.1.2，印刷页 212–214，[PDF 第 233–235 页](../../Query%20opt.pdf#page=233)。本节定义 Bag 的并、交、差，解释截断减法和 `∪max`，并把运算规则连接到 SQL 的 `UNION ALL` 与重复敏感语义。

## 三种运算的逐点定义

对任意元素 `z`，Bag 运算直接作用于重数：

> `χˣ∪ᵦʸ(z) = χˣ(z) + χʸ(z)`
>
> `χˣ∩ᵦʸ(z) = min(χˣ(z), χʸ(z))`
>
> `χˣ∖ᵦʸ(z) = χˣ(z) ∸ χʸ(z)`

其中截断减法定义为：

> `a ∸ b = max(0, a - b)`。

它保证重数不会变成负数。

## 一个元素的计算

设：

> `χˣ(a)=5`，`χʸ(a)=3`。

那么：

| 运算 | `a` 的结果重数 |
| --- | ---: |
| `X ∪ᵦ Y` | 8 |
| `X ∩ᵦ Y` | 3 |
| `X ∖ᵦ Y` | 2 |
| `Y ∖ᵦ X` | 0 |

因此 Bag 并不是“只保留一份 a”。它把左右输入中的出现次数相加，这对应 SQL 的 `UNION ALL` 风格。需要去重时，必须另行使用显式的 duplicate elimination；下一节会定义它。

## 哪些集合规律还成立

重数加法和最小值都满足交换律、结合律；因此 Bag 并和 Bag 交仍满足这些规律。交还满足幂等律：`X ∩ᵦ X = X`。

差仍然不满足交换律或结合律。集合中的一些分配律也会失效。例如，集合有：

> `X ∩ (Y ∪ Z) = (X ∩ Y) ∪ (X ∩ Z)`。

Bag 中这个方向不再一般成立，因为左侧的最大保留次数是一次 min，而右侧可能把两个交集的重数相加。

反过来的一个分配式却成立：

> `X ∪ᵦ (Y ∩ᵦ Z) = (X ∪ᵦ Y) ∩ᵦ (X ∪ᵦ Z)`。

它依赖非负整数上的恒等式：

> `x + min(y,z) = min(x+y,x+z)`。

下一节会完整展开这条证明，并用同样的重数方法构造失败方向的反例。

## `∪max` 与本书的 Bag 并

原书特别提醒：集合论中常见的 Bag union 是最大重数并：

> `χˣ∪ₘₐₓʸ(z) = max(χˣ(z), χʸ(z))`。

本书主要使用的 `∪ᵦ` 是重数相加；它是 SQL 和许多查询语言的 union all 语义。两者不要因为都叫 union 就混用：如果 `a` 在左右两边分别出现 2 次和 3 次，`∪ᵦ` 得到 5 次，`∪max` 得到 3 次。

原书还给出：

> `X ∪max Y ≡ (X ∖ᵦ Y) ∪ᵦ Y`。

它说明即使只保留加法并、交和差，也可以表达最大重数并；但这不改变两种 union 的语义差异。

## 本节的证明工具

集合等价可以逐个元素检查是否存在；Bag 等价必须逐个元素比较重数。后续所有 Bag 改写都应先问：对任意 `z`，左右两边的 `χ(z)` 是否相等？如果不能逐点证明，就需要给出具体重数反例。
