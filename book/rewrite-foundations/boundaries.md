## B03 · 相等类一节不能只记“可以替换”

**位置：§5.5，pp.204–206。状态：上下文已读，具体例式待逐式复核。**

原文区分三值相同和 false-interpreted 后相同。教学必须保留这一层；不能把 WHERE 上成立的替换搬到 CHECK 上。该节部分概括性文字也需谨慎，例如 SQL 相等的两侧交换仍产生相同真值，但它不是把所有值都纳入普通二值等价关系的相等。讲解应以定义和真值表为准，不笼统复述“相等不对称”。

## B04 · FD、键与重复出现

**位置：§6.1–2，pp.207–208；§7.3.3，p.225。状态：边界已核对。**

两份完全相同的 `[a:1,b:2]` 满足值层面的 a→b，却仍构成有重复的 bag。FD 不单独推出无重复；当后文使用 TID 时，约束涉及的是行的出现身份。含 NULL 的 FD、SQL 的具体唯一约束和作者的点等号定义不能自动视为同一件事。

## B05 · 聚合分解、可逆性与恒等化的限制

**位置：§7.2，pp.217–220；§7.11.1，p.267。状态：已读，部分反例已核对。**

原文的分解定义首先限定非空分块；含 NULL 的 avg 又改用 non-null count。这些条件需要贯穿后续推导。将 `sum(a₁+a₂)` 拆成两个 sum 的算例必须处理 NULL：其中一列为 NULL 时，两边可能忽略不同的行。

p.220 关于 singleton 上聚合等于原值的文字排除了 count(*)，但 count(a) 同样不能一般变成恒等函数：count({7})=1。p.267 以 map 消除分组的公式应按具体聚合改写，不能对 count 直接复制原属性。

关于 DISTINCT 的“不可分解”讨论，应说明所允许的中间状态和具体聚合类别；不将其泛化成任何大小、任何类型的中间结果都不可能分解。正式授课时按原文签名和例子重新整理。

## B07 · 弱线性复合和分类表的缺失条件

**位置：§7.4.1–2，pp.235、238。状态：p.238 已查看页面图像；以下反例为教材核验。**

p.238 声称弱线性函数的复合仍弱线性，其推导没有保证中间结果不相交。令 g 将每个输入值都映为同一值 c，并保留出现次数；令 f 是去重。g 强线性，f 弱线性。

取 X={a}ᵦ、Y={b}ᵦ 且 a≠b。X、Y 不相交，但 f(g(X∪ᵦY)) 只有一份 c，而 f(g(X))∪ᵦf(g(Y)) 有两份 c。因此一般弱线性复合结论不成立。教材可安全解释强线性复合；弱线性复合需补中间 support 条件或其他足够条件。

同样应复核 Table 7.1 中去重投影的弱线性分类。令 X={[a:1,b:2]}、Y={[a:1,b:3]}，它们不相交，但去重投影到 a 后发生碰撞；两边分别为一份和两份 `[a:1]`。不能把表格全部机械照搬。

## B08 · 更换分组键不能只保留单向 FD

**位置：§7.11.1，pp.266–267，式 (7.101)。状态：已查看 p.267 页面图像，反例已核对。**

引入段同时假设 H→G 与 G→H；公式后的文字只保留 H→G，容易被误读成充分条件。令 G={a}、H={b}，输入为 `[a:1,b:10]` 和 `[a:1,b:20]`。H→G 成立，但按 G 分组只有一组，按 H 分组有两组。以 count 为聚合时两边不同。

教学先使用双向 FD 保证组划分一致，再解释投影和组内常量复制。是否存在其他更弱的条件另行论证，不直接采用公式后面的简化文字。

## B09 · 空组、补 NULL 行与 groupjoin 默认值

**位置：§7.3.6、§7.3.10；§7.11.7，pp.286–289。状态：定义已读，p.287 已看图；等价家族待逐式核验。**

Γ 按实际出现的键产生组，因此空输入与空键集合并不自动生成一组。GJ 的定义则为每个左输入项对匹配 bag 调用 f；匹配 bag 可以为空。

p.286–287 对 count(*) 的默认值讨论出现了从空 bag 的 0 改到全 NULL 单行的 1 的转换。按 p.231 的 GJ 定义，无匹配时 count(*) 应基于空 bag；而“outerjoin 后再聚合”会看到补出的单行。两种上下文不能混同，(7.186)–(7.191) 暂不作为已经验证的通用等价使用。

教材将分别写清目标构造、空输入与补行，再检查默认值，而不是在全书范围内重新定义 count(*) 的空输入结果。
